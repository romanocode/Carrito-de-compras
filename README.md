# 🛒 Carrito de Compras - Cursos en Línea

Un proyecto  que simula una tienda de cursos en línea con funcionalidad completa de carrito de compras implementada con JavaScript vanilla.

## 📋 Descripción

Este proyecto es una aplicación web que permite a los usuarios navegar por una selección de cursos y gestionar un carrito de compras.

## ✨ Características

- **Agregar cursos al carrito**: Los usuarios pueden añadir cursos con un solo click
- **Control de cantidad**: Si un curso ya existe en el carrito, incrementa automáticamente la cantidad
- **Eliminar productos**: Posibilidad de remover cursos individuales del carrito
- **Vaciar carrito**: Función para limpiar completamente el carrito
- **Interfaz responsive**: Diseño adaptable a diferentes dispositivos
- **Persistencia visual**: Los títulos de la tabla se mantienen siempre visibles

## 🚀 Tecnologías Utilizadas

- **HTML5**: Estructura semántica de la página
- **CSS3**: Estilos y diseño responsive (Skeleton CSS Framework)
- **JavaScript ES6**: Lógica del carrito y manipulación del DOM


## 🛠️ Funcionalidades Implementadas

### Carrito de Compras
- ✅ Añadir productos al carrito
- ✅ Incrementar cantidad de productos existentes
- ✅ Mostrar información del producto (imagen, título, precio, cantidad)
- ✅ Eliminar productos individuales
- ✅ Vaciar todo el carrito
- ✅ Feedback visual en tiempo real

### Gestión de Eventos
- ✅ Event delegation para botones dinámicos
- ✅ Prevención de comportamientos por defecto
- ✅ Manejo eficiente de eventos del DOM
